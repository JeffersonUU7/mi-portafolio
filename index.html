Proyectos

Mamá Toyo: pedidos para llevar y menú del día

Sistema web para un comedor de San Miguel donde el cliente ve el menú, hace su pedido con anticipación y la cocina recibe la lista de pendientes. Proyecto de Gestión de Servidores Web en un equipo de 6 personas, donde coordiné el equipo y escribí la documentación.

Arquitectura: navegador, Apache con HTTPS y reverse proxy, y API en Express y TypeScript dentro de un contenedor Docker. El diseño final prevé un balanceador Nginx con PostgreSQL.
